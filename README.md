# FitBuddy 💚

FitBuddy is a beginner-friendly health and fitness web application built using FastAPI and HTML.

## Features

- BMI Calculator
- BMI Category
- Diet Plan
- Workout Plan
- Simple and user-friendly interface

## Technologies Used

- Python
- FastAPI
- HTML
- CSS
- Jinja2 Templates

## How to Run

1. Clone this repository.
2. Install the required Python packages.
3. Run the FastAPI application.
4. Open the application in your browser.
